# MicroMove — PWA de microejercicios

App para recordatorios de microejercicios instalable en Android.

## Archivos incluidos
- `index.html` — App principal
- `sw.js` — Service Worker (notificaciones en segundo plano)
- `manifest.json` — Config PWA
- `icon-192.png` / `icon-512.png` — Iconos

## Cómo publicar gratis en GitHub Pages

1. Crear cuenta en https://github.com (si no tenés)
2. Crear repositorio nuevo → nombre: `micromove` → Public
3. Subir todos estos archivos al repositorio
4. Ir a Settings → Pages → Source: Deploy from branch → main → / (root) → Save
5. En ~1 minuto va a estar disponible en: `https://TU_USUARIO.github.io/micromove`

## Cómo instalar en el celular Android

1. Abrir Chrome en el Android
2. Ir a la URL de arriba
3. Chrome va a mostrar un banner "Agregar a pantalla de inicio" — tocarlo
4. O: menú ⋮ → "Instalar app" / "Agregar a pantalla de inicio"
5. Aceptar el permiso de notificaciones cuando lo pida
6. ¡Listo! Aparece como app en el home y funciona en segundo plano
